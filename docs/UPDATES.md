# Автообновление

Приложение умеет само находить и ставить новые версии (Sparkle). В сборке из репозитория оно **выключено**:
не указано, где публикуются обновления, и нет ключа подписи. Ничего никуда не публикуется, пока вы не решите где.

## Как это устроено

- Приложение раз в день скачивает `appcast.xml` — короткий список версий со ссылками на dmg.
- Каждый dmg подписан ключом разработчика (EdDSA). Приватная часть ключа лежит только в Связке ключей вашего Mac,
  публичная — внутри приложения. Приложение ставит только то, что подписано вашим ключом: подменить обновление
  по дороге или на сервере нельзя.
- Найдя новую версию, приложение предлагает её (ненавязчиво: окно не выскакивает посреди звонка), скачивает,
  заменяет себя и перезапускается. Снимать карантин (`xattr`) после обновления не нужно — установщик Sparkle делает это сам.
- Выключить можно в Настройки → «Общие» → «Обновления» → «Проверять обновления автоматически»; там же «Проверить сейчас»
  и в меню приложения «Проверить обновления…».

## Что нужно сделать один раз

1. **Выбрать публичное место** для двух видов файлов: `appcast.xml` и dmg. Подойдёт, например:
   - GitHub Releases для dmg и GitHub Pages для appcast.xml;
   - любое хранилище с HTTPS-ссылками (Yandex Object Storage, S3, свой сайт).

   Адрес ленты должен начинаться с `https://` — иначе приложение его не примет.
2. **Создать ключ подписи.** После первой сборки через `Tools/dmg/make-dmg.sh` инструменты Sparkle лежат в
   `build/ReleaseDerivedData/SourcePackages/artifacts/sparkle/Sparkle/bin`. Запустите оттуда `./generate_keys`:
   приватный ключ сохранится в Связку ключей, а в терминале появится публичный.
   **Приватный ключ никуда не копируйте и не коммитьте.** Потеряете его — старые версии не смогут обновиться.
3. **Вписать два значения** в `project.yml` (цель `CallRecorder`, `settings.base`):
   ```yaml
   UPDATE_FEED_URL: "https://…/appcast.xml"
   SPARKLE_PUBLIC_KEY: "публичный ключ из generate_keys"
   ```
   Только сборки с этими значениями будут искать обновления: версию, собранную без них, один раз
   придётся обновить вручную.

## Каждый выпуск

1. Поднимите `MARKETING_VERSION` и `CURRENT_PROJECT_VERSION` в `project.yml` (Sparkle сравнивает `CURRENT_PROJECT_VERSION`).
2. `Tools/dmg/make-dmg.sh --public` — соберёт dmg, подписанный собственным сертификатом «Transcribation» из Связки
   ключей (без него — без сертификата). В приложение не попадут имя, почта и Team ID разработчика, а один и тот же
   сертификат сохраняет выданные macOS разрешения от версии к версии.
3. `DOWNLOAD_URL_PREFIX=https://…/ Tools/release/make-appcast.sh` — положит dmg в `build/updates/` и перепишет
   `appcast.xml`, подписав его ключом из Связки ключей. Скрипт ничего не загружает.
4. Загрузите содержимое `build/updates/` в выбранное место. Приложения у всех найдут версию в течение суток
   (или сразу по «Проверить обновления…»).
